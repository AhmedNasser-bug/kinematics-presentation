### 4. Local localhost CRM Security Audit Checklist
*   **Hardcoded Secret Audit:** Reject plain text passwords, API keys, or JWT tokens in the codebase. Enforce `.env` variables and verify `.gitignore` ignores configuration secrets.
*   **Local Port Bindings Check:** Verify database and backend services are bound strictly to localhost (`127.0.0.1`) and not `0.0.0.0` or open network IPs.
*   **Host Isolation:** Isolate localhost development instances from live client networks; verify no real customer database dumps are stored unencrypted on local dev disks.

### 5. Engineering & Operational Guardrails
*   **Code Redundancy:** Always enforce version control, complete API key insulation, and multi-tenant isolation schemas. Banish localhost database hosting for production tools.
*   **Performance Metrics:** Keep page loads sub-second to protect ad conversion rates. Highlight Astro v5 static compilation and GSAP animations.
